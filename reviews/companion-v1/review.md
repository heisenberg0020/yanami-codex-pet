# 小卖部 v0.1 · 实际验收

日期：2026-09-10。决定：首版可交付试用，保留原版动作，继续根据真实使用反馈扩展。

## 已交付

本地 React 小卡片、Node 原子存档服务、独立 Mac 菜单栏应用。6 种点心、24 句原创投喂短句、12 则见闻、3 种偶遇纪念贴纸。15/25/45 分钟采购与明确标注的30秒体验；库存、投喂收藏和小票均持久化。

本机应用为 arm64、macOS ≥13.5，Swift 编译、Info.plist、内置 Node 和 ad-hoc 签名校验通过。不是已公证的公开安装包。

## 发现后已修复

1. 启动计时首次渲染偶尔显示00:31：响应到达时同步当前时间，并以设定时长约束显示。复测25:00及原生00:30正确。
2. 领取弹窗发生错误时，重试提示落在不可点击的弹窗外：弹窗内也提供错误和同编号确认入口。
3. 服务可能已写入文件但返回503：保留原操作编号；发送前写标签页恢复记录，刷新后继续确认，不能用新编号再次投喂。
4. 不确定状态仍显示“已本地保存”：改为“等待确认保存”。
5. 无纪念物时出现空白“顺手带回”：改为完整的见闻文案。
6. 窄屏气泡遮挡与319px导航溢出：调高人物区、调整极窄屏导航，已复看实际页面。

## 范围与尚未覆盖

这是独立小卡片，可在Codex浏览器面板使用；尚未接入原生Mini点击菜单或Codex任务事件。原生Codex应用控制此前受工具限制，本次未尝试修改宿主或绕过限制，也未切换原生宠物。

完整真实等待使用30秒体验；15/25/45分钟跨暂停与时间推进通过领域测试，没有在本轮各等完一轮。休眠和系统时间变化以可控时间测试验证，未让用户Mac实际休眠。菜单栏状态项打开菜单尚未独立点击验收；应用自动打开、主菜单退出、重启和WKWebView均已实际验证。

首版不提供专注真实性检测、通知、云同步、任意时长、自动采购或自由聊天。待确认操作的恢复记录仅保留在同一个标签页会话中；关闭整个会话后可重新查看已保存库存与小票。长期大量记录下的性能尚未压测。
