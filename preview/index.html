审阅说明与兼容边界

正常播放采用本机 2026-09-10 核实的时序：idle 为 6 帧，时长 1680 / 660 / 660 / 840 / 840 / 1920 ms；其他状态完成 3 轮后回 idle。循环审阅只方便检查当前动作，不代表宿主会持续保持该状态。方向角从屏幕上方 0° 起，顺时针每 22.5° 一格。

小尺寸采用宿主 CSS 默认宽度 7.04rem 在根字号 16px 下的 112.64px；实际 Mini 尺寸还受应用设置与缩放影响。脚底线是可调审阅参考，不代表系统碰撞或角色的实际锚点。

此页仅用 CSS background-position 裁格，不修改图片，不连接 Codex，不模拟任务事件、鼠标追踪、桌面移动或应用缩放。原生减少动态模式只选首帧；系统偏好减少动态时本页默认暂停。

动画 WebP 有自己的图像时钟。播放、暂停、逐帧和慢放只控制宿主裁格时钟，不能冻结或重置 WebP 内部动画；本页适合静态 v2 atlas 审阅。

revision 为手动审阅标签，也可用 URL 参数 ?revision=名称 预填；它不验证 Git 提交、素材哈希或质量结论。更新文件后点“重新读取素材”，两侧共用同一裁格时钟。

快捷键：空格播放/暂停，← / → 逐帧。素材缺失或尺寸不符会明确显示，绝不会拿原版替代候选。列号与行号从 0 开始。
