# 动画审阅器

无框架、无安装依赖。请从**仓库根目录**启动静态服务：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/preview/>。不要从 `preview/` 目录启动服务，也不要通过 `file://` 打开 ES modules。

- 左侧读取 `assets/upstream/yanami-anna/spritesheet.webp`，右侧读取 `pets/yanami-anna-refined/spritesheet.webp`。候选不存在或图集尺寸错误时明确显示错误，不使用替代图。重新读取会绕过浏览器素材缓存。
- 原版与候选共用裁格时钟；9 个状态、16 个方向覆盖宿主使用的所有格子。方向从屏幕上方 0° 开始，顺时针每格 22.5°。
- **原生时序**：idle 6 帧共 6.60 秒；非 idle 状态播放 3 遍，随后循环 idle。**循环审阅**只重复当前状态；**减少动态**只显示所选状态第 0 格。三种模式明确分开。
- 暂停、逐帧、0.5×/0.25×、浅/深/棋盘背景、48/96/112.64/192/288px 宽度、格子边框、可调脚底参考线用于检查节奏与边缘。48×52 与 96×104 用于小图可读性验收，112.64px 为宿主 CSS 基准。空格和左右方向键可控制播放；表单控件有焦点时保留浏览器按键行为。
- revision 是手动标签，可用 `?revision=local-v1` 预填。它不验证 Git SHA、文件哈希或质量结论。页面始终显示 `candidate` 和“尚未实机验收”，不会写入验收通过记录。

## 兼容范围

该页面是**浏览器预览，不是 Codex 实机验收**。只通过 CSS background-position 裁格，不修改原图，不接入或操作 Codex。9 个状态的时序、帧数和方向映射来自 2026-09-10 本机宿主的只读核实，代码中注明观察到的 bundle 与函数名。

帧表：`[6,8,8,4,5,8,6,6,6,8,8]`；单格 `192 × 208`；图集 `1536 × 2288`。idle 为 `[280,110,110,140,140,320] × 6`。其他各行普通帧/末帧毫秒：run-left/right `120/220`，waving `140/280`，jumping `140/280`，failed `140/240`，waiting `150/260`，running `120/220`，review `150/280`。

112.64px 为宿主 CSS 默认 7.04rem 在 16px 根字号下的换算；实际 Mini 可受缩放与设置影响。脚底线是人工参考，不是宿主锚点。此页不模拟应用事件、桌面运动或鼠标追踪。

**动画 WebP 限制**：图片内部时钟独立于裁格时钟。暂停、逐帧、慢放、从头播放都不能可靠暂停或重置图像内部动画；此页的精确帧审阅针对静态 atlas。系统减少动态偏好让页面默认暂停，但也不能冻结动画 WebP。

## 检查

无额外依赖的时序检查：

```sh
node --test preview/animation.test.mjs
```

浏览器审阅建议：选 9 状态，核对三轮回 idle；逐帧看角色比例、眼眉嘴和格子边缘；选 16 朝向核对最终两行；切深浅底检查白边；以小尺寸检查可读性。候选缺失与错误尺寸应看到明确消息。浏览器通过仍需真实 Codex 中的人工验收。
