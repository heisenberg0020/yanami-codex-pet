# 八奈见的小卖部 · Mac 启动器

独立的菜单栏应用，使用 AppKit 窗口与 WKWebView 打开本机小卖部。界面约 940 × 760，最小 760 × 600；关闭窗口后保留菜单栏入口，可选择“打开小卖部”“在浏览器中打开”或“退出小卖部”。Bundle ID 为 `com.heisenberg.yanami-snack-club`。

## 构建与运行

需要 macOS、Xcode Command Line Tools，以及与当前 Mac 架构一致的 Node。先在仓库根目录完成网页依赖安装，再运行：

```sh
npm run build
bash macos/build.sh
open "dist/八奈见的小卖部.app"
```

也可以用仓库的 `npm run mac:build` 完成前两步。指定其它输出位置或 Node：

```sh
bash macos/build.sh --output "/完整路径/八奈见的小卖部.app" --node "/完整路径/node"
```

构建脚本只打包已有 `companion/dist`，不会自动安装依赖或修改网页。应用内包括 Swift 启动器、当前 Node、Node 许可文本、`companion/*.mjs` 和网页产物；服务只用 Node 内置模块，因此不需要打包 `node_modules`。网页使用的角色与零食资源必须已进入 `companion/dist`。

默认从 Node 安装目录的 `bin/../LICENSE` 读取随发行版附带的许可。Node 放在其它位置时，可加 `--node-license "/完整路径/LICENSE"` 指定同一发行版的许可文件。

每次构建会检查 Node 架构、其最低 macOS 版本和动态库依赖。依赖包外动态库的 Node 会被拒绝；请选用独立 Node 发行版。输出为当前架构，最低系统要求取启动器的 macOS 12 与 Node 要求中的较高值。本次开发机的 Node 要求 macOS 13.5。应用采用本地 ad-hoc 签名，未做开发者签名、公证或跨机兼容验收。

同一输出位置的旧版小卖部会先保留为 `.app.backup-时间-编号`；发现其它应用或符号链接则停止构建。更新前应先从菜单栏退出正在运行的旧版，再打开新版。

## 本地入口与记录

默认入口为 `http://127.0.0.1:17653/`。记录由服务写入：

```text
~/Library/Application Support/YanamiSnackClub/state.json
```

启动日志位于同目录下的 `logs/launcher.log`；启动时发现日志超过 1 MiB 会保留一份 `launcher.previous.log`。壳本身不读写游戏存档。

可直接启动应用内的可执行文件来传入环境变量，避免 Finder 或已运行实例忽略新参数：

```sh
YANAMI_PORT=17654 \
  "dist/八奈见的小卖部.app/Contents/MacOS/YanamiSnackClub"
```

支持 `YANAMI_PORT`、`YANAMI_DATA_FILE`、`YANAMI_DIST_DIR`。后两项接受本地路径，建议使用绝对路径；默认分别是上述存档和应用内网页目录。自定义配置前先退出旧实例。使用同一端口时会复用已有小卖部服务，该服务原有的存档与网页设置不会被新环境变量改变；需要隔离数据时请同时使用不同端口和存档路径。

## 服务的启动与退出

启动器等待 `GET /api/state` 返回成功、正确结构以及 `X-Yanami-Service: yanami-snack-club-v1` 后才加载网页，最长等待约 15 秒。该标记用于识别服务，不是身份认证机制。

- 已有同服务：复用，不接管其进程；退出应用后它继续运行。
- 端口被其它服务占用：显示错误，不终止占用进程。可另选端口重新启动。
- 自己启动的服务：关闭窗口后继续运行；从菜单选择退出时先正常终止，超时再结束这个子进程。
- 连接或网页失败：显示重试入口。重新打开窗口、重试或打开浏览器时会再次检查服务。

应用只使用 `127.0.0.1` 的本地网页。用户主动点击外部网页链接时交给默认浏览器；壳不操控 Codex，不更改其宠物配置。此版本没有登录自启动、系统通知、全局快捷键或自动更新。

## 验收范围

Swift 编译、打包、签名检查与网页测试不能替代原生窗口验收。构建脚本完成后仍需实际核对：

- 打开应用，菜单栏图标出现，原版角色和零食页面正常显示。
- 调整窗口至最小尺寸、输入文字、切换页面，界面可用。
- 关闭窗口后能从菜单栏重开，浏览器入口可打开同一记录。
- 服务已运行时可复用；占用端口时提示清楚，原占用进程继续运行。
- 退出应用后，仅自己的子服务结束；重新打开后存档保留。

当前文档不预填原生 GUI 通过结果。请在项目验收记录中写明应用版本、系统、操作与实际结果。
