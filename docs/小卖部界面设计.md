# 小卖部界面设计 · v0.1

方向：日式文具与便利店小票，温柔、安静、明确。参考图仅供布局与配色；实际角色只读取原版图集，禁止使用概念图里重新绘制的人物。所有文字与控件由页面原生渲染。

色彩：纸色 #f7f5ee，正文海军蓝 #203d63，辅助文字 #64758a，浅蓝 #e5eff5，黄油色 #f5dc91，白色 #ffffff。边界 #d5dee3。无需远程字体；正文使用系统中文无衬线，主标题使用系统中文衬线，数字等宽。

布局：桌面最大宽度1120，外边距32；顶部标题与三个导航。主卡片左右比约42:58，左侧原版角色与短句，右侧采购操作。下方六格抽屉预览。窄屏将角色与操作上下排列，抽屉每行两格，按钮至少44高。

层级：产品名22/粗体，主标题36–44/衬线，页面标题30，正文15/1.7，辅助13。圆角主卡24、子块14、按钮12；阴影只用于浮起的小票与对话框。

组件：主导航、原版sprite、采购控制器、点心插画、库存条目、收藏条目、小票弹层、投喂反馈、取消确认。三个页面为“专注采购 / 零食抽屉 / 收藏册”。

交互：开始即保存截止时间；暂停/取消有清晰反馈。采购归来先展示小票，领取成功才增加库存。投喂成功才扣除零食并记录收藏。请求不确定时允许以同一个操作ID重试，避免重复发放。加载失败显示恢复入口，不显示假数据。新用户的一份起始零食为真实本地库存；30秒体验始终明确标注且不计专注分钟。

动态：使用原版preview/animation.mjs的原生时序；有限反应播放三次后回待机。可开启减少动态，也跟随系统偏好。没有新的角色帧、随机跳动或声音。

生成资产：reviews/companion-v1/concept.png 为整屏概念；companion/public/art/snacks.webp 为六点心图集。采用内置图像生成工具；提示词保存在reviews/companion-v1/art-prompts.json。点心图按3×2正方格读取，未替换或加工角色图集。
