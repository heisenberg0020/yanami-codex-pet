# 首版执行计划：零食收藏 + 专注采购

状态：v0.1 已实施并完成本轮验收。日期：2026-09-10。

实际结果、修复项与未覆盖范围见 [首版验收记录](../reviews/companion-v1/review.md)。

## 交付物与边界

交付一个本地运行的陪伴小卡片和 Mac 菜单栏启动器，完整支持“开始专注 → 采购归来 → 领取小票与点心 → 投喂 → 收藏保存”。浏览器与菜单栏卡片共享同一份本地数据。角色读取原版图集，原生 Codex 宠物的文件、默认动作和选择状态保持独立。

首版包含 6 种点心、约 24 条投喂短句、12 条采购见闻、3 类纪念贴纸；新用户获得每种一份初始点心。15/25/45 分钟专注，可暂停、继续与取消。额外提供明确标注的 30 秒体验采购，不计入专注分钟。真实采购、体验采购在小票中区分。

暂不纳入自动 Codex 事件、房间布置、自由聊天或新人物动作。页面文案不声称卡片能控制原生 Mini，也不把对话结束当成任务成果。

## 实施顺序

1. 固化状态与内容：计时、领取、防重复、投喂、收藏、本地存档。
2. 完成小卡片设计与点心插画，提取配色/排版规则。
3. 实现专注采购、抽屉、收藏三个页面；复用原版动作和时序。
4. 加入本地服务与原子存档，处理重启、睡眠、重复请求和多个窗口。
5. 打包 Mac 菜单栏启动器；本地网页保留为可独立测试的入口。
6. 实际完成一次 30 秒体验采购，并验证投喂、领取、重载、重复点击和移动尺寸。发现问题先修复再复测。
7. 更新 GitHub 文档、测试与启动方式，交付可运行产物。

## 状态约定

专注：空闲 → running → paused → running → ready → 领取后空闲。取消回到空闲，不扣点心。运行倒计时以截止时间计算，暂停保存剩余时间，不依赖后台标签页每秒执行。

点心：inventory 数量只能是非负整数。每次投喂只消费一份，记录首次/最近赠送时间与次数，使用不连续重复的对应台词。库存耗尽时禁用投喂。

采购结果在开始时固定；刷新不会重抽。一次采购最多领取一次，重复请求不能重复发放。15/25/45分钟分别带回1/2/3份点心；体验带回1份。贴纸为约三分之一机会的偶遇。小票记录模式、时间、点心、故事与可选纪念物；试用采购专注明确为 0 分钟。

原图集 SHA-256 应一直为 41d2ed83cdd7285a8cbf441fc530b11bce7e6e0c0345192aaf3b2e6a19fa3fe3。首次交付与后续验收均核对。

## 代码分工与公共接口

- companion/catalog.mjs：6 个点心、12 则故事、3 个纪念物。
- companion/domain.mjs：纯状态变换，所有时间与 ID 都由参数传入，可测试。
- companion/store.mjs / server.mjs：仅绑定127.0.0.1，串行原子写入、备份恢复、同源写入检查、静态页面。
- companion/src/：React 页面与原版 sprite 显示；根 package.json 和 Vite 配置由主代理管理。
- macos/：Swift 菜单栏壳及构建脚本，由独立子任务实现。
- companion/tests/：按行为验收测试，覆盖计时与重复领取等真实风险。

服务约定：GET /api/state 返回 {state, catalog, now, recoveryNotice?}。POST /api/actions 接受 {id, type, expectedRevision, payload}，type 为 start/pause/resume/cancel/claim/feed/settings；成功返回 {state, catalog, now, feedback?}。失败返回 {error:{code,message},state?}，冲突409，校验400。POST的id为操作幂等ID。start的payload为 {minutes:15|25|45,mode:"focus"} 或 {mode:"trial"}；feed为 {snackId}；settings为 {reducedMotion:boolean}。其它payload为空。默认生产端口17653，开发可指定独立端口和数据文件。

domain导出 createInitialState(now)、applyAction(state,action,now)、viewState(state,now)、validateState(value)。applyAction返回 {state,feedback?} 或抛带code/message/status的错误；不做I/O。状态schemaVersion=1，revision数字，createdAt时间戳，inventory映射，collection映射，receipts数组，feeds数组，activeTrip|null，settings。activeTrip包含id/mode/status/durationMs/remainingMs/deadlineAt/startedAt/reward；计时到期由viewState或applyAction转为ready。记录与所有时间为epoch毫秒。目录与私有存档不提交GitHub。

## 验收门槛

- 正常与30秒体验流程都可领取并投喂，体验不伪装实际专注。
- 暂停跨重启保持；运行跨重启/休眠后按实际时间恢复；取消无扣减。
- 重复领取、快速双击、多窗口过期操作不产生双倍物品或负库存。
- 存档失败不能把界面显示为成功；损坏存档有恢复说明，不能默默清空。
- 三个页面、空状态、结果弹层、键盘操作在桌面与窄屏可用。
- 原版角色图集不变，减少动态可用；关闭卡片不影响原生宠物。
- 浏览器实际测试与 Mac 壳的构建/实际启动分开记录，未观察的项目不写通过。
